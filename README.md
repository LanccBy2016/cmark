# CMark

本地 Markdown 笔记。文件是你的，版本用 Git 管，随时能带走。

跑在 [ZTools](https://github.com/ztools) 插件体系里。

## 为什么用它

### 笔记就是文件

磁盘上的 `.md`，没有数据库、没有私有格式、没有云端账号。

用任何编辑器都能打开，用 Git 就能同步、回溯、协作。哪天真不想用了，直接删掉软件，
笔记一篇不少 —— 这一点从第一行代码起就没打算妥协。

### 导出结果和编辑区一模一样

Markdown / HTML / PDF / 长图，四种格式都是直接对编辑区做快照。

不是「再拿另一个渲染器重画一遍」，所以不会出现那种经典事故：编辑时图表好好的，
导出来图没了、公式散了、代码没颜色。你看到什么，导出的就是什么。

### 图表画在笔记里

流程图、时序图、统计图，写在代码块里就能直接看到渲染结果。

源码还在，随时能改；图表也不占用独立节点，换到别的编辑器打开还是一段正常的代码块。

### 表格能真的编辑

增删行列、调整对齐，点按钮就行，不用背 Markdown 语法。

### 粘贴即存图

截图直接 `Ctrl+V`，自动落进笔记目录，按内容命名去重。

不塞 base64、不把单篇笔记撑成几兆，也不会因为一处引用断开就全篇失效。

### Git 在侧边栏

当前分支、未提交改动、提交历史、拉取推送 —— 都在左侧，不用切到终端。

写笔记的人不一定要懂 Git，但需要的时候它就在那儿。

### 还能顺手做的

全文搜索并高亮命中、源码模式带行号、只读模式防手滑、正文字号五档可调、
代码块 27 种语言高亮、公式行内块级都支持、图片可缩放、
`==高亮==` `^上标^` `~下标~` `[TOC]` `[[双链]]` 这些扩展语法也都认。

## 安装

从 ZTools 插件市场安装。

## 开发

```bash
npm install
npm run dev      # 本地调试
npm run build    # 构建，产物在 dist/
npm run pack     # 打包成 ZTools 插件
```
